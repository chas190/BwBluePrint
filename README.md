# BwBluePrint

BwTown web projects and independent development solutions.

## Uplift Foundation V2

The `uplift_foundation_v2_GPT/` directory contains the responsive Uplift Foundation website. It introduces the mission, investment stewardship, project oversight, sustainable development alignment, and place-based community impact.

## UpSports V2 GPT

The `upsportspro_v2_GPT/` directory contains the independent UpSports website, including the homepage and Hometown Economy page. All project images are included in the repository.

## AppLink Dashboard V2 GPT

The `applink_dashboard_v2_GPT/` directory contains the AppLink dashboard application.

## IFEWA Foundation V2

## Brighton Community V2

## Stage This Home Setup React V2

`stage_this_home_setup_v2_GPT/` contains the React home setup catalog converted from the standalone Stage This setup app. It includes the sample product catalog, editable ASIN and image fields, Excel/CSV import, selected package reporting, Amazon integration guidance, and a browser-session audio workspace.

Published path: https://chas190.github.io/BwBluePrint/stage_this_home_setup_v2_GPT/

Amazon live prices and product images require an approved Amazon data source and a secure server integration. The current app displays its documented price references and generated Associates-tagged search links.
