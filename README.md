# BwBluePrint

BwTown web projects and independent development solutions.

## Uplift Foundation V2

The `uplift_foundation_v2_GPT/` directory contains the responsive Uplift Foundation website. It introduces the mission, investment stewardship, project oversight, sustainable development alignment, and place-based community impact.

## UpSports V2 GPT

The `upsportspro_v2_GPT/` directory contains the independent UpSports website, including the homepage and Hometown Economy page. All project images are included in the repository.

## AppLink Dashboard V2 GPT

The `applink_dashboard_v2_GPT/` directory contains the AppLink dashboard application.
