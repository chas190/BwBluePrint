# Paladin Logistics V2

Static, responsive recreation of the supplied Paladin WordPress website with original local images and navy/yellow branding. No WordPress server or build dependencies are required.

Open `index.html` or serve this directory with any static server. Edit `app.js`, `styles.css`, and `content.js` to change content and layouts. Hash routes support GitHub Pages and subdirectory hosting.

Published path: https://chas190.github.io/BwBluePrint/paladin_logistics_v2_GPT/

Original slideshow images were externally referenced and absent from the archive; the hero uses the included road-freight banner. Team photos are original theme assets associated with the demonstration team layout. Template statistics, pricing, clients and staff are identified as demonstration material. Quote forms download a text request; no request is transmitted. Tracking needs a carrier integration. Source database, WordPress configuration, credentials and personal account data are excluded from this project.
