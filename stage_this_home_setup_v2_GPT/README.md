# Stage This Home Setup (React)

React conversion of the supplied standalone home setup catalog.

## Run locally

```sh
npm install
npm run dev
```

## Features

- 60 sample kitchen items across nine categories
- Search, category collapse, item selection, and package estimate
- Excel and CSV catalog import
- Product image upload or image URL, editable ASIN field, Amazon links
- Selected item CSV export and print view
- Session audio upload with in-browser playback
- Amazon integration notes and server-side credential guidance

The sample prices are planning references. Amazon live catalog data requires an approved API/feed and a secure backend; this source does not contain live Amazon credentials.
