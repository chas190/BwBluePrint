## Development
Run npm ci, then npm run dev. Run npm run build for production.
The GitHub Pages workflow builds and publishes this folder with the other V2 projects.

## Source limitations
The application form is a demo that simulates submission; it does not send applications.
The source references podcast.mp3, but that file is absent from the repository and returns 404 on the original site. The V2 dialog displays an availability message.
