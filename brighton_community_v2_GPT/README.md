# Brighton Community V2 GPT

Mobile-first BwTown community partnership concept for Brighton, Alabama.

Live: https://chas190.github.io/BwBluePrint/brighton_community_v2_GPT/

Buildless static HTML, CSS, and JavaScript. Serve this folder directly. The shared repository Pages workflow copies it into the combined deployment.

Includes a right-side town menu, leadership and legacy partner directories, individual profile previews, PWA manifest, and scoped offline caching. Comments, profile edits, favorites, priorities, and partner introductions are local to each browser; no shared submission backend is connected.

Official names are attributed to the Brighton city staff directory; unverified council and partner positions are labeled. The hero is an AI-generated community vision, not a photograph of a completed Brighton project.
